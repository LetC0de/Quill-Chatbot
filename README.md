# Quill

## Project Description

Quill is an Enterprise Knowledge Assistant that lets users upload documents and query them using AI-powered RAG (Retrieval-Augmented Generation). It supports secure document management, contextual conversations, and real-time streaming responses.

## Features

- **Document Upload & Management** — Upload, store, and organize documents with automatic vector embeddings
- **AI-Powered Q&A** — Ask questions about your documents with context-aware responses
- **Conversational Interface** — Multi-turn conversations with message history and persistence
- **RAG Architecture** — LangGraph-backed retrieval pipeline with summary and fact-based query detection
- **Real-time Streaming** — Streamed AI responses via FastAPI and React
- **Dockerized** — Single-command deployment with Docker Compose
